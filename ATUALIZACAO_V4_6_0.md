# FIN360 4.6.0 — Insights Financeiros

## O que foi incluído

- Nova aba **Insights** no menu principal.
- Índice de saúde financeira calculado com os dados já cadastrados.
- Comparação de despesas com o mês anterior.
- Identificação da maior categoria de gastos.
- Alerta de utilização dos cartões.
- Projeção do saldo após contas programadas.
- Resumo de metas, projetos, contas e investimentos.
- Links diretos para os módulos relacionados.

## Preservação da base

A tela é somente analítica: não cria, edita ou exclui lançamentos. Todos os módulos e dados da versão 4.5.4 foram preservados.
