# FIN360 4.6.3 — Gestão Inteligente de Status

## Melhorias

- Novo status explícito no cadastro de lançamentos.
- Despesas: Pendente / Pago.
- Receitas: A receber / Recebido.
- Alteração rápida do status diretamente no card do lançamento.
- Registro da data de pagamento ou recebimento quando o item é baixado.
- Ao voltar um lançamento para pendente/a receber, a data de baixa é removida.
- Edição do lançamento usa o mesmo seletor visual de status.
- Filtro de status continua compatível com dados antigos.
- Parcelamentos mantêm parcelas futuras como pendentes; a primeira parcela respeita a escolha do usuário.
- Compatibilidade com os dados já salvos em versões anteriores.
